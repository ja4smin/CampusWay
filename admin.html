CampusWay Admin needs the local server

The admin screen saves to a small database on your PC, so it only works when CampusWay is started with the local server. Open a terminal in the CampusWay folder and run:

node server/campusway-server.js

Then open http://localhost:8080/admin.html. On Windows you can also double-click start-admin.bat.

Create the first administrator account. It is stored only on this PC, in server/db/users.json (the password is hashed).
