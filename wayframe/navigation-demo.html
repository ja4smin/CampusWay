How this demo works
Choose a floor first; the location dropdown then contains only rooms and useful destinations from that floor. Scroll the mouse wheel to zoom. Click and drag the map to explore it manually. During navigation, the marker moves only when phone motion sensors detect a physical step. The route graph constrains movement so the marker stays on the planned path. Use Recenter to return to automatic follow mode.
